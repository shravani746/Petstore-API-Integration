# Petstore API Integration

This project is a React application that integrates with the Swagger Petstore API. It allows users to view, add, update, and delete pets using the Petstore API. The app features a modern, user-friendly interface for interacting with the API's data.

## Features

- View a list of pets with details such as ID.
- Add a new pet with attributes such as name, status, and category.
- Update the details of an existing pet.
- Delete a pet from the system.
- Display success/failure messages (using toast notifications) for API operations like add, update, and delete.

## Technologies Used

- React: Front-end library for building the user interface.
- Axios: For making HTTP requests to the API.
- React Router: For handling page navigation.
- CSS: Styling for the app.
- React Toastify: For displaying success/failure messages.
